# DoodleLab - Agent Instructions

These conventions apply to all branches and all future work in this repository.

---

## AI attribution policy

Do not add any AI assistant or model attribution to repository artifacts.

This includes, but is not limited to:

- `Co-Authored-By` trailers referencing Claude, Anthropic, or any AI model.
- "Generated by Claude Code" or equivalent statements in commit messages.
- AI-related signatures or metadata in commit messages.
- AI attribution in source code comments, README files, specifications, ADRs, or other
  documentation.
- Automatically generated AI attribution metadata of any kind.

---

## Git authorization policy

Never execute history-changing Git operations without explicit authorization from @Grace.

Operations that require explicit authorization before execution:

- `git commit`
- `git push`
- `git push --force`
- `git merge`
- `git rebase`
- `git reset`
- `git cherry-pick`
- `git tag` (annotated or signed)

Writing or updating a file is not authorization to commit it. Wait for explicit instruction.

Do not alter existing Git history. Do not modify global Git configuration.

---

## Formatting conventions

Use only the ASCII hyphen `-` (U+002D) in generated source files and documentation.

Do not use:

- En-dash (U+2013)
- Em-dash (U+2014)
- Hyphen characters from other Unicode ranges
