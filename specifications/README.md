Il documento integrale è stato fornito per l'audit di conformità del bootstrap P-01, ma non è versionato in questo repository. Per verificare di avere la stessa versione usata come baseline:

```sh
shasum -a 256 "Master Prompt - Agenda ADHD v2.3.4.pdf"
```

L'hash deve coincidere con il valore indicato sopra. Un hash diverso indica un documento diverso: in quel caso i riferimenti a sezioni e pagine contenuti in `docs/` vanno ricontrollati.

I riferimenti nei documenti di DoodleLab usano i numeri di sezione del Master Prompt e, dove utile, i titoli dei paragrafi.
